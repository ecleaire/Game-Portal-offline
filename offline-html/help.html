目次

はじめに

保存先を選ぶ → ゲームを追加 → カードを押して遊ぶ

  1. GAME-PORTAL.htmlをPC版Chromeで開きます。
  2. ホームの「ゲームのフォルダーを選ぶ」で保存先を選び、アクセスを許可します。
  3. 追加・変更する人は「設定」→「編集モード」をオンにします。遊ぶだけならオフのままで使えます。
次回も同じフォルダーを使う

「次もこのフォルダーを使う」は最初からオンです。許可が残っていれば次回は自動接続します。許可が切れたら「設定」→「再接続する」。初回設定は保存先を選ぶと自動で済みます。

ゲームを追加する

  1. 編集モードで「＋ ゲームを追加」を押します。
  2. HTML・WebゲームZIP・PYXAPPは「ファイルを選ぶ」。展開済みなら「フォルダーを選ぶ」で素材一式を選びます。
  3. チェック結果と追加先を確認して「追加する」を押します。
  4. ゲーム名・作ったソフトを入力して「保存」。タグ・サムネイル・概要・操作方法も設定できます。

サムネイルはJPG・PNGがおすすめです。「あとで設定」で閉じても追加した作品は残り、後から編集できます。

追加できる形式・サイズ
  • HTML・HTM、WebゲームZIP、Pyxel PYXAPP。Scratchのsb3は先にHTMLに変換します。
  • ZIP・PYXAPPは50MB以内。展開後・フォルダー一式は200MB・500ファイル以内です。
  • JS・画像・音声などを別ファイルで使う作品は、すべて含めてZIPまたはフォルダーで追加します。
  • EXEは「Windows EXE」の手順を確認してください。
「アップロード」で元のゲームは変わる？

選んだゲームを保管フォルダーへコピーします。元のファイルは変更しません。選択だけでは保存せず、「追加する」を押す前ならキャンセルできます。

Scratch（sb3）をHTMLにする

TurboWarp Packagerで変換したHTMLを追加します。

1. Scratchの作品を保存する

Scratchで作品を開き、「ファイル」→「コンピューターに保存する」から .sb3 を保存します。すでにsb3があれば次へ進みます。

2. PackagerでHTMLに変換する

  1. TurboWarp Packagerを開く ↗（外部サイト・ネット接続が必要）。
  2. プロジェクトの読み込みでファイルから読み込む項目を選び、sb3を指定します。公開作品はScratchのURLやIDからも読み込めます。
  3. タイトル・画面サイズなどを確認します。初めてなら、必要な項目以外はそのままで進めます。
  4. 出力形式をHTML（Plain HTML・単体HTML）にします。
  5. 「パッケージ化（Package）」を実行し、できた .html を保存します。言語によって表示名は異なります。

3. GAME PORTALに追加する

  1. 「＋ ゲームを追加」→「ファイルを選ぶ」で、できたHTMLを選びます。
  2. 「追加する」を押し、ゲーム名と「作ったソフト」を設定します。作ったソフトはScratchまたはTurboWarpにして保存します。
  3. カードを開き、操作・音・表示を確認します。ネット接続を切った状態でも遊べるか確認してください。
変換・起動で迷ったら
  • sb3はそのまま追加できません。拡張子をhtmlに変えるだけでは変換できません。編集用のsb3は別に残します。
  • ZIPで出力した場合：Web用のHTMLと素材を含むZIPならそのまま追加できます。展開済みならフォルダー一式を選びます。
  • 動かない機能がある：外部通信・クラウド変数・追加の拡張機能が必要な作品は、このランチャー内では動かない機能があります。
  • ネットがない場所で変換：事前に公式のオフライン版の案内 ↗を確認し、TurboWarp Desktopなどを用意します。

参考：TurboWarp公式ドキュメント ↗

Godot・Pyxelのゲームを用意する

Godot

  1. Web向けに書き出します。
  2. 出力されたHTML・JS・WASM・PCKなどをすべてまとめます。
  3. ZIPにして「ファイルを選ぶ」、または一式を「フォルダーを選ぶ」で追加します。

HTMLやPCKだけでは動きません。スレッド必須のWeb書き出しは対象外です。

Pyxel

Pyxelでpackageした .pyxapp を追加します。準備後にゲーム画面をクリックして開始します。同梱版はPyxel 2.9.9です。ネットから追加パッケージを取得する作品は対象外です。

遊ぶ・ゲーム情報を編集する

遊ぶ

カードの画像かゲーム名を押すと開きます。「全画面」で広げ、Escキーで戻ります。「← ゲーム一覧」で一覧へ戻ります。概要と操作方法はゲーム画面の下に表示されます。

情報を編集する

  1. 編集モードでゲームを開き、「編集」を押します。
  2. 名前・作ったソフト・タグ・サムネイル・概要・操作方法を変更して「保存」します。

ゲーム名と作ったソフトは必須です。作ったソフトはタグにも自動で加わります。ゲーム本体を変える場合は「ゲーム本体を更新」を使います。

サムネイル・設定を元に戻す

JPG・PNGの指定がおすすめです。「プレイ画面を撮影」と切り抜きは補助として使えます。変更を戻したい場合は、編集画面の「設定履歴」から以前の名前・タグ・画像などを復元できます。

ゲームを探す

検索欄にキーワードを入力します。検索欄を押すと出る「くわしくさがす」では形式・作ったソフト・タグも組み合わせられます。「絞り込みを解除」で条件を戻します。

Windows EXEゲーム

メイン画面はHTMLです。EXEの起動にだけWindows用の補助を使います。

  1. HTMLと同じフォルダーのGAME-PORTAL-WINDOWS.exeを開きます。
  2. 単体EXEは「ファイルを選ぶ」。DLL・素材がある場合は「フォルダーを選ぶ」で一式を追加します。ZIPは先に展開します。
  3. カードを開き、「EXEを起動」を押します。初回は補助側でもHTMLと同じ保管フォルダーを選びます。

Windowsの別ウィンドウで動きます。信頼できるゲームだけ実行してください。セーブはゲーム自身が管理し、HTMLのセーブ履歴・画面撮影の対象外です。

フォルダーのまとめ方・更新・再接続
  • 選ぶフォルダーの直下に主な起動用EXEを1つ置きます。Godotの同名consoleとUnity CrashHandlerは付属として扱います。合計200MB・500ファイル以内です。
  • 更新はゲーム終了後、同じ場所のEXEと素材を交換します。作品情報JSONとゲーム固有セーブは残します。
  • 接続が外れたら、タスクトレイのGAME PORTALから「HTMLを開く」を選びます。補助を終了しても起動中のゲームは終了しません。

ゲーム本体を更新する

  1. 編集モードでゲームを開き、「本体を更新」を押します。
  2. 新しいファイル・フォルダー一式を選び、チェック結果を確認します。
  3. 「確認して本体を更新」を押します。「起動を再試行」で新版を確認できます。

名前・タグ・画像・概要・操作方法・作品IDは引き継ぎます。「前の本体に戻す」で旧版へ戻せます。

対象とセーブについて

対象は「ゲームを追加」で追加したWebゲーム・PYXAPPです。直接配置した作品は、投稿で専用フォルダーへ追加してから更新します。EXEは「Windows EXE」の手順を使います。

更新・旧版復元前に、対応するこのPCのセーブを自動退避します。退避に失敗した場合は本体を切り替えません。セーブが新版で使えるかはゲーム側の互換性に依存します。旧版は残るため、更新すると使用容量が増えます。

共有・別PCへ持ち運ぶ

同じゲームを共有する

  1. 各PCで同じNAS・共有フォルダーを選び、アクセスを許可します。
  2. 「ほかのPCの変更を自動で表示」をオンにします。原則15秒ごとに一覧へ反映し、「一覧を更新」ですぐ確認できます。

ゲームと作品情報は共有できます。セーブは各PCに保存されます。同じ作品の同時編集・同時更新は避けてください。

フォルダーごと渡す

HTMLとゲーム保管フォルダー全体をコピーし、相手PCでも初回は保存先を選びます。別々にコピーしたフォルダー同士は、その後は自動同期しません。

共有用HTML・バージョンの注意

「設定」→「共有・バージョン」→「共有用HTMLを保存」で案内用パスを含むHTMLを作れます。ゲーム・セーブ・アクセス許可はHTMLに含めません。同じPC・Chromeで同じHTMLを使う場合は保存先の選択も共有し、プレイ・編集後に切り替えます。

全PCのHTMLを先に v0.14.0 以降の対応版へ交換してください。必要版と合わない場合は新規起動・投稿・編集を止めます。v0.13.1以前にはこの判定がありません。古いHTML・ショートカットも交換し、互換性情報は削除しないでください。Windows補助はHTMLと同じ版を使います。

情報・履歴・更新版・旧版も含めてコピーし、管理用ファイルを個別に改名しないでください。プレイ中のゲームは他PCの更新で終了せず、開き直すと新版になります。

セーブを守る・持ち運ぶ

対応Webゲームのセーブは、このPCのChrome内に保存します。NASへは自動同期しません。

別PCへ移す

  1. ゲームを開き、「セーブ書き出し」からJSONを保存します。
  2. 相手PCで同じ作品を開き、「セーブ読み込み」でそのJSONを選びます。

以前のセーブに戻す

「セーブ履歴」で日時を選び、「このセーブに戻す」。復元直前のセーブも残るので戻し直せます。履歴は作品ごとに直近10件です。

保存の対象・気をつけること

対象はHTML・ZIPのlocalStorage相当のデータです。ゲーム独自のIndexedDB・Pyxel独自ファイル・EXEのセーブは対象外です。本体更新・旧版復元前に対応セーブを自動退避します。ブラウザーの保存データを消すとセーブと履歴も失われるため、必要なものはJSONへ書き出します。同じChromeプロファイルを使う人同士はセーブを共有します。

ゲームを一覧から外す・削除する

HTML内に削除ボタンはありません。保管フォルダーで操作します。

  1. 編集モードでゲームを開き、「編集」→「保存先を確認」で対象を確認します。
  2. ゲームを終了します。EXEはWindows側のゲームも終了します。
  3. 追加した作品のフォルダーを保管フォルダーの外へ丸ごと移動します。戻す予定がなければ削除します。
  4. 「一覧を更新」。共有先の他PCでも自動確認後に一覧から消えます。
直接置いたゲーム・セーブについて

直接配置した作品は本体・情報JSON・専用素材が対象です。他作品と共用の素材は削除しないでください。各PCのWebゲームのセーブは、作品フォルダーを削除しても自動削除されません。

困ったとき

ゲームを追加・編集できない

保存先を選び、「設定」→「編集モード」をオンにします。書き込み許可も確認し、ボタン付近の案内に従ってください。

ゲームが起動しない・ファイルが足りない

HTMLと素材一式があるか確認します。sb3はHTMLへ変換、GodotはWeb用の一式を追加します。「設定」→「ゲームを点検」で不足や壊れた設定を確認し、接続後に「起動を再試行」を押します。外部サーバー必須の作品・スレッド必須のGodot Web書き出しは対象外です。

一覧に反映されない・接続が切れた

NASなどの接続を戻し、「設定」→「再接続する」、続いて「一覧を更新」。切断時は自動確認を停止するため復帰操作が必要です。追加・編集中や画面が非表示の間も自動反映は待機します。

「保存結果未確認」「更新結果未確認」が出た

繰り返し保存・投稿せず、結果を確認します。設定の保存は「保存結果を確認」。本体更新は「本体を更新」→「更新状態を確認」。投稿途中の作品は「設定」→「ゲームを点検」で確認できます。

EXEを起動できない

同じ版のGAME-PORTAL-WINDOWS.exeからHTMLを開き直し、補助側でも同じ保管フォルダーを選びます。Windowsの実行権限とDLL・素材も確認します。起動中ならゲームを終了してから再度起動します。
