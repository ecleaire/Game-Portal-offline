# Windows EXEゲーム対応（ベータ版）

**EXEゲーム対応・Windows起動補助はベータ版です。**

メイン画面は **GAME-PORTAL.html** です。Webゲームは従来どおりHTMLだけで使えます。

EXEゲームを使う場合は、同じフォルダーに **GAME-PORTAL-WINDOWS.exe** を置いて開きます。
GitHubの「Code → Download ZIP」を展開すると、HTMLと起動補助が同じフォルダーに入っています。
補助アプリが同じHTMLをChromeなどの標準ブラウザーで開き、EXE起動に接続します。
Windows 10 / 11向けで、Node.js・Python・Electronのインストールは不要です。

フォルダー選択を省略するプレイ専用の自動接続も試せます。`GAME-PORTAL-FOLDER.txt` の準備方法は[自動接続の案内](AUTO_CONNECT.md)を参照してください。

1. HTMLでゲームの保存先を選びます。前回の許可が残っていれば自動接続します。
2. 編集モードで「ゲームを追加」。単体EXEはファイル、DLLや素材が必要なゲームはフォルダー一式を選びます。
3. カードを開いて「EXEを起動」を押します。補助アプリから初めて起動するときは、HTMLと同じ保管フォルダーを選びます。
4. EXEゲームはWindowsの別ウィンドウで動きます。HTMLの一覧へ戻ってもゲームは終了しません。

EXEはブラウザーの保護範囲外で動きます。信頼できるゲームだけ実行してください。
Windowsのアクセス権やセキュリティ設定によって実行できない場合は、HTMLにエラーを表示します。
EXEを含むZIPは、先に展開してからフォルダー一式を追加してください。
フォルダーの直下に起動用EXEを1つ置きます。Godotの同名 `.console.exe` とUnityのCrashHandlerは付属ファイルとして扱います。別の起動用EXEが複数ある場合は、ゲームごとにフォルダーを分けてください。追加できるのは合計200MB・500ファイル以内です。

セーブはEXEゲーム自身が管理します。HTMLのセーブ書き出し・履歴・バックアップの対象外です。
EXE本体を更新する場合はゲームを終了し、保管フォルダーの同じ場所へ本体と素材を入れ替えます。
作品情報の `.gameportal.json` とゲーム固有のセーブは残してください。EXEの画面撮影と自動本体更新は対象外です。

同じタブでHTMLを再読み込みしても、起動補助との接続を引き継ぎます。起動補助を終了した場合や新しいタブで開く場合は、タスクトレイのGAME PORTALから「HTMLを開く」を選びます。
補助アプリを終了する場合もタスクトレイを使います。起動中のゲームは終了しません。
接続情報は起動中だけ使い、共有用HTML・ソースZIPへ保存しません。

通常のHTMLと同じファイルを開くため、Webゲームのブラウザー内セーブをそのまま使えます。
Windows版ZIPを別の場所へ展開した場合は、従来どおり保存先の再指定が必要になる場合があります。
