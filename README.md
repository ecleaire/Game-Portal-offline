# GAME PORTAL

バージョン：**0.27.12**

フォルダーに保存したゲームを、オフラインで探して遊ぶランチャーです。ゲームの追加、名前・サムネイル・タグなどの編集にも対応しています。アカウント登録は不要で、保存先にはPC内のフォルダーやNASを指定できます。

Windows・Mac・Mojaveのアプリでは、ゲームを別ウィンドウで表示します。HTML版はGoogle Chromeのページ内で遊べます。ゲーム本体やセーブを移すときは、下の保存・バックアップの案内を確認してください。

v0.27.12では、NASをバックアップから復元するなどして共有セーブの履歴が分かれた場合、このPCのセーブを残して使うデータを確認します。

Intel Macは **macOS 10.14以降**、AppleシリコンはmacOS 11以降に対応します。アプリや起動補助の内部ファイルは取り出さず、一式で使用してください。

詳しくは[変更履歴](docs/CHANGELOG.md)をご覧ください。

## ダウンロードして使う

**[v0.27.12のZIPをダウンロード](https://github.com/ecleaire/Game-Portal-offline/archive/refs/tags/v0.27.12.zip)**

展開すると **`Game-Portal-offline-0.27.12`** フォルダーになります。

GitHubの **Code → Download ZIP** を使う場合は、先にタグ **`v0.27.12`** を選んでください。[リリース情報](https://github.com/ecleaire/Game-Portal-offline/releases/latest)で変更内容を確認できます。インストール・ビルド・Actionsの操作は不要です。Mac用エンジンを含むためZIPは約800MBあります。ダウンロード完了後、**ZIP全体を展開してから**起動してください。

**ゲーム本体はZIPに含まれていません。** 遊ぶゲームを保存したフォルダーを用意してください。

1. `Windows`・`Mac`・`HTML` から使う環境を選びます。
2. 遊ぶだけなら **プレイ用**、ゲームを追加・編集するなら **クリエイター用**を開き、下の表のファイルを起動します。
3. 初回はゲームの保存先フォルダーを選びます。設定画面へのフォルダードラッグでも接続できます。
4. ゲームのカードを押して遊びます。

| 環境 | プレイ用 | クリエイター用 |
| --- | --- | --- |
| Windows 10 / 11（64bit） | `GAME-PORTAL-PLAY.exe` | `GAME-PORTAL.exe` |
| Mac（Intel：10.15以降／Appleシリコン：11以降） | `GAME-PORTAL-PLAY-MAC.app` | `GAME-PORTAL-MAC.app` |
| Mac（Intel：Mojave 10.14） | `GAME-PORTAL-PLAY-MOJAVE.app` | `GAME-PORTAL-MOJAVE.app` |
| HTML（Windows・MacのGoogle Chrome） | `GAME-PORTAL-PLAY.html` | `GAME-PORTAL.html` |

Windows・Macアプリはベータ版です。Mac版はエンジンを同梱し、Chromeの別インストールは不要です。初回は起動の準備に時間がかかります。2回目以降は準備済みのデータを利用します。Mojaveで使う場合は、上の表の `*-MOJAVE.app` を選んでください。詳しくは[Macの案内](docs/MAC.md)を確認してください。HTML版はGoogle Chromeで開き、保存先へのアクセスを許可します。

## プレイ用とクリエイター用の違い

**遊ぶ人はプレイ用、ゲームを登録・管理する人はクリエイター用**を選びます。両方で同じゲームの保存先を使えます。

| 機能 | プレイ用 | クリエイター用 |
| --- | --- | --- |
| ゲーム検索・タグ絞り込み・プレイ | ○ | ○ |
| 対応セーブの保存・書き出し・読み込み | ○ | ○ |
| ゲームの追加・対応作品の本体更新 | ― | ○ |
| 名前・サムネイル・タグ・作成ツールなどの編集 | ― | ○ |
| 作品情報の書き出し・読み込み | ― | ○ |
| ほかのPCへの保存先設定の共有（EXE・APP） | ― | ○ |

クリエイター用は最初から **編集モードがオン** です。閲覧だけにするときは **設定 → 編集モード** をオフにでき、次回もその選択を保持します。ゲームごとに名前・画像・タグ・概要・操作方法を設定でき、タグは作成ツールのタグも含めて、1作品につき32個まで使えます。

HTML・WebゲームのZIP・展開済みフォルダー・Pyxelの`.pyxapp`に対応しています。GodotはWeb書き出し一式、Scratch（sb3）はHTMLへ変換して追加します。WindowsのEXEゲーム対応はベータ版で、MacではEXEゲームを実行できません。詳しい準備・操作はアプリ内の **ヘルプ** にあります。

## ゲームを追加・編集する

クリエイター用で、先にゲームの保存先を選びます。

1. **＋ ゲームを追加**を押し、ゲームのファイルまたはフォルダーを選びます。
2. 確認結果を読み、**追加する**を押します。選んだゲームは保存先へコピーされます。
3. ゲーム名・作成ツール・タグ・サムネイルなどを設定し、**保存**を押します。
4. 後から変更するときは、ゲームのカードを開いて **編集**を押します。

**編集内容は「保存」を押して確定します。** 閲覧しているだけでは作品情報を変更しません。対応作品のゲーム本体を差し替えるときは **本体を更新**を使います。

## プレイ中の操作

| 操作 | 動作 |
| --- | --- |
| ゲーム一覧 | セーブを確認してゲームを終了し、一覧へ戻る |
| 再読込 | 今開いているゲームを起動し直す |
| 全画面 | ゲームを全画面で表示する |

アプリ版ではランチャー側に **プレイ画面へ**と **ゲーム一覧へ**を表示します。ゲーム用ウィンドウを閉じても、セーブを確認してから一覧へ戻ります。編集などの操作画面が開いている場合は、その操作を保存・完了してから戻ってください。

## NASで共有する

EXE・APP版では、次の手順でほかのPCの初回フォルダー選択を省けます。

1. 展開した**ランチャー一式**とゲーム保管フォルダーを、同じNAS共有内に置きます。配布フォルダーの配置は保ちます。
2. 最初のPCでNAS上の**クリエイター用EXE／APP**を開き、ゲームの保存先を選びます。
3. **設定 → この保存先を共有**を押して確認します。ランチャーの場所への書き込み権限が必要です。
4. ほかの未設定PCで、同じNAS上のプレイ用またはクリエイター用EXE／APPを開くと、自動で接続します。

共有設定を使って接続したPCは、クリエイターが **この保存先を共有** で共有先を変更すると、開いているプレイ用でもホームで自動確認します。ゲーム中・編集中・保存中は切り替えを待ちます。一時的に接続できない場合は間隔をあけて再確認します。

NASへのログイン・OSのアクセス許可は各PCで必要です。パスワードは共有設定へ保存しません。個別に保存先を設定済みのPCは、自動では切り替わりません。別々にコピーしたランチャーやゲームフォルダーの間では同期しません。

同じ作品を複数の画面・PCで編集した場合、古い内容での保存は止められることがあります。「設定が更新されています」と表示されたら、入力内容を控えてから一覧を更新し、最新の作品情報を開き直してください。「保存結果未確認」の場合は再保存せず、先に保存結果を確認します。

同じ保存先を使うと、ゲームと作品情報を共有できます。すぐ反映するには **一覧を更新**を押します。一覧と作品情報は、ホームで操作が落ち着いたときに約30秒ごと（Mojave版は約1分ごと）に確認します。遅い保存先では確認間隔を延ばします。ゲーム中や編集中は更新を保留します。対応するセーブも、保存を許可すると共有できます。EXE・Pyxel独自のセーブなどは対象外です。

HTML版では初回のフォルダー選択・アクセス許可がPC・ブラウザーごとに必要です。[HTMLの起動補助](docs/AUTO_CONNECT.md)も利用できます。PC内のゲームはネット接続なしで遊べますが、NAS利用時にはNASへ接続できるネットワークが必要です。

## 保存・バックアップ・更新

| データ | 保存場所 |
| --- | --- |
| ゲーム本体 | 設定で選んだ保存先フォルダー |
| 名前・画像・タグなど | ゲームごとの `.gameportal.json` |
| 対応セーブ | このPCのアプリ／ブラウザー内。共有を許可すると保存先にも同期 |
| お気に入り・最近遊んだ履歴 | 利用中のアプリ／ブラウザー内。ほかのPCとは共有しません |
| 前回の保存先・表示設定 | このPCのアプリ／ブラウザー内 |

バックアップや別PCへの移行では、設定・履歴を含めて**ゲーム保管フォルダー全体**をコピーしてください。**フォルダーのコピーだけでは、このPC内にしかないセーブやお気に入り・履歴は移りません。**

アプリ版とHTML版ではPC内のセーブ領域も異なります。続きを移すときは対応セーブの共有か書き出し・読み込みを使い、移行先で読み込めることを確認してから元データを整理してください。[受け渡し手順](docs/TRANSFER_GUIDE.md)にまとめています。

ランチャーを更新するときはアプリを閉じ、最新版ZIPを別の場所へ展開してから入れ替えてください。ゲーム保管フォルダーや、運用中の `GAME-PORTAL-CONNECTION.json`・`GAME-PORTAL-FOLDER.txt` は残します。`_内部ファイル`・`_runtime`・`.app` の中身は削除・変更しないでください。

## 困ったとき

### 作品情報の保存に失敗したとき

**「保存結果未確認」と表示されたら、保存ボタンを繰り返し押さず、先に結果を確認します。**

1. NASへの接続や空き容量を確認し、保存に使った同じゲーム保管フォルダーへ接続します。
2. **保存結果を確認**を開き、画面内の **保存結果を確認**ボタンを押します。
3. 保存済みなら再保存は不要です。未反映の場合だけ **履歴の保存内容を再試行**を選べます。
4. 別の変更がある場合は再試行で上書きせず、一覧を更新して最新の作品情報を確認します。

v0.27.2以降では、履歴や復旧記録を準備できない段階では設定ファイルを作りません。保存途中の失敗では、履歴と復旧記録を残します。アプリやHTMLを開き直した後も確認できます。ゲーム本体・設定ファイル・ブラウザーの保存データは、復旧のために手動で削除しないでください。

### 接続や保存データの問題

保存記録の形式エラーが出た場合は、ブラウザーの保存データを削除せず、[保存記録エラー時の対応](docs/STORAGE_ERRORS.md)を確認してください。

- 接続が止まったら **接続待ちを中止 → 設定** から保存先を選び直します。NASは先にエクスプローラーやFinderで開けるか確認してください。
- 保存先の記憶を削除すると、そのPCでは選び直すまで自動接続しません。ほかのPCの設定やセーブは保持します。
