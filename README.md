# GAME PORTAL

バージョン：**0.24.2**

フォルダーに保存したゲームを、オフラインで探して遊べます。
アカウント登録は不要です。ゲームの保存先は設定から選べます。自分のPCのフォルダーのほか、NASの共有フォルダーも指定できます。

## ダウンロードして使う

**[ZIPをダウンロード](https://github.com/ecleaire/Game-Portal-offline-html/archive/refs/heads/main.zip)**

GitHubの **Code → Download ZIP** からもダウンロードできます。Actionsの操作は不要です。
Mac用の表示エンジンを含むため、ZIPは約800MBあります。ダウンロードが完了したら、ZIP全体を展開してから起動してください。

1. ZIPを展開し、使う環境の **Windows／Mac／HTML** フォルダーを開きます。
2. **プレイ用** または **クリエイター用** を開き、下の表のファイルを起動します。
3. 初回はゲームの保存先フォルダーを選びます。設定画面の枠へのドラッグでも接続できます。
4. ゲームのカードを押して遊びます。

| 使う環境 | プレイ用 | クリエイター用 |
| --- | --- | --- |
| Windows 10 / 11（64bit） | `GAME-PORTAL-PLAY.exe` | `GAME-PORTAL.exe` |
| Mac（Intel：10.14.6以降／Appleシリコン：11以降） | `GAME-PORTAL-PLAY-MAC.app` | `GAME-PORTAL-MAC.app` |
| Google Chrome（Windows・Mac） | `GAME-PORTAL-PLAY.html` | `GAME-PORTAL.html` |

Windows・Macアプリはベータ版です。Mac版は表示エンジンを同梱し、アプリ内でゲームを開きます。Google Chromeの別インストールや、ブラウザーのフォルダーアクセス許可は不要です。
Intel向けの互換版は `GAME-PORTAL-PLAY-MOJAVE.app`／`GAME-PORTAL-MOJAVE.app` です。詳しくは[Macでの使い方](docs/MAC.md)を確認してください。

HTML版はGoogle Chromeで開きます。保存先フォルダーへのアクセスを許可すると、ブラウザー内でゲームを管理・プレイできます。

ゲームは配布ZIPに含まれていません。共有して遊ぶときは、ゲームを管理する人に保存先を確認してください。
`_内部ファイル`・`_runtime` は変更せず、配布フォルダーごと保管してください。Mac版は表示エンジンも `.app` 内に含み、アプリ全体をコピーして使えます。初回の起動準備が終わるまでお待ちください。

## 遊ぶ・ゲームを管理する

**遊ぶ人はプレイ用、ゲームを登録・管理する人はクリエイター用**を選びます。

| 機能 | プレイ用 | クリエイター用 |
| --- | --- | --- |
| ゲームの検索・タグ絞り込み | ○ | ○ |
| ゲームのプレイ・対応セーブ | ○ | ○ |
| ゲームの追加・削除・本体更新 | ― | ○ |
| 名前・サムネイル・タグなどの編集 | ― | ○ |
| 作品情報の書き出し・読み込み | ― | ○ |

プレイ用にはゲームの追加・編集ボタンを表示しません。クリエイター用で変更するときは **設定 → 編集モード** をオンにします。

両方で同じゲームの保存先フォルダーを使えます。プレイ用でも対応するゲームのセーブは保存できます。

- ゲーム名・作成ツール・タグ・サムネイル・概要・操作方法を設定できます。サムネイルはJPG・PNGがおすすめです。
- 自分のタグを作り、1作品に32個まで設定できます。
- 作品情報はゲームごとに保存します。JSONへの書き出し・読み込みは、個別・選択・一括で行えます。ゲーム本体・セーブは含みません。

HTML・WebゲームのZIP・展開済みフォルダー・Pyxelに対応しています。GodotはWeb書き出し一式、Scratch（sb3）はHTMLに変換して追加します。WindowsのEXEゲーム対応はベータ版です。準備方法はアプリ内の **ヘルプ** で確認できます。
WindowsのEXEゲームはMacでは起動できません。

## データの保存場所

| データ | 保存場所 |
| --- | --- |
| ゲーム本体 | 設定で選んだゲームの保存先フォルダー |
| ゲーム名・タグ・サムネイルなど | ゲームごとの `.gameportal.json` 設定ファイル |
| プレイ中の対応セーブ | このPCのアプリ／ブラウザー内。共有を許可すると保存先フォルダーにも同期 |
| 前回の保存先・表示設定 | このPCのアプリ／ブラウザー内 |

ゲームの設定は、クリエイター版の編集画面から変更できます。共有やバックアップの際は、設定・履歴などを含めてゲームの保存先フォルダー全体をコピーしてください。
アプリ版とHTML版では、このPC内のセーブ保存領域が異なります。続きを移す場合は、対応セーブの共有か書き出し・読み込みを使います。

## 次回の起動と、ほかのPCとの共有

### EXE・APPで、ほかのPCの初回設定を省く

1. 展開した**ランチャー一式**とゲームの保管フォルダーを、同じNASの共有フォルダー内に置きます。`Windows`・`Mac`・`_内部ファイル` などの配置は保ちます。
2. 最初のPCでNAS上の**クリエイター用EXE／APP**を起動し、ゲームの保存先を選びます。
3. **設定 → この保存先を共有**を押して確認します。ランチャー一式の場所への書き込み権限が必要です。
4. ほかのPCで、同じNAS上の**プレイ用またはクリエイター用EXE／APP**を起動します。未設定のPCは共有された保存先へ自動で接続するため、アプリ内でフォルダーを選ぶ必要はありません。

共有するのは保存先への接続設定です。NASへのログイン・OSのアクセス許可は各PCで必要です。設定ファイルにパスワードは保存しません。ゲームの保存先は相対パスとIDで確認するため、PCによってドライブ名やNASのマウント先が異なっても、同じ配置で接続できます。

共有先を変更するときも、クリエイター用で保存先を選んでから **この保存先を共有**を押します。個別に保存先を記憶済みのPCは、自動では切り替えません。別々にコピーしたランチャー間では接続設定は同期されません。

### 次回の起動・ゲームとセーブの共有

前回の保存先を記憶し、アクセスできれば自動接続します。HTMLではブラウザーの許可が必要です。初回や許可が切れたときは、画面の案内に従って許可してください。**HTMLをブックマークしておくと、次回も開きやすくなります。**

アプリで保存先の記憶を削除すると、そのPCでは選び直すまで自動接続しません。ほかのPCの接続先やセーブは変わりません。

Windows・Mac・HTMLで **同じ共有フォルダー** を使うと、ゲームと作品情報を共有できます。ホームで3分間操作しないと、画面や検索条件を保ったまま変更を確認します。すぐ反映するには「一覧を更新」を押してください。別々にコピーしたフォルダーの間では、自動同期しません。

PC内のゲームを遊ぶときは、インターネット接続は不要です。NASを使う場合はNASに接続できるネットワークが必要で、各PCで共有フォルダーへのアクセス権を用意します。HTML版のフォルダー許可もPC・ブラウザーごとに行います。

対応するゲームのセーブも共有できます。初回は保存を許可してください。EXE・Pyxel独自のセーブなどは対象外です。詳しくはヘルプの「セーブ」を確認してください。

## 困ったとき・詳しい手順

接続が進まない場合は **「接続待ちを中止」→「設定」** から、保存先を選び直すか枠へドラッグしてください。NASは先にエクスプローラーやFinderで開けるか確認します。
