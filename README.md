# GAME PORTAL

バージョン：**0.24.15**

フォルダーに保存したゲームを、オフラインで探して遊ぶランチャーです。ゲームの追加、名前・サムネイル・タグなどの編集にも対応しています。アカウント登録は不要で、保存先にはPC内のフォルダーやNASを指定できます。

今回の更新では、お気に入りをキーボードで解除した後も続けて操作できるように改善しました。使い方の案内も整理しています。詳しくは[変更履歴](docs/CHANGELOG.md)をご覧ください。

## ダウンロードして使う

**[v0.24.15のZIPをダウンロード](https://github.com/ecleaire/Game-Portal-offline/archive/refs/tags/v0.24.15.zip)**

展開すると **`Game-Portal-offline-0.24.15`** フォルダーになります。

GitHubの **Code → Download ZIP** を使う場合は、先にタグ **`v0.24.15`** を選んでください。[リリース情報](https://github.com/ecleaire/Game-Portal-offline/releases/latest)で変更内容を確認できます。インストール・ビルド・Actionsの操作は不要です。Mac用エンジンを含むためZIPは約800MBあります。ダウンロード完了後、**ZIP全体を展開してから**起動してください。

**ゲーム本体はZIPに含まれていません。** 遊ぶゲームを保存したフォルダーを用意してください。

1. `Windows`・`Mac`・`HTML` から使う環境を選びます。
2. 遊ぶだけなら **プレイ用**、ゲームを追加・編集するなら **クリエイター用**を開き、下の表のファイルを起動します。
3. 初回はゲームの保存先フォルダーを選びます。設定画面へのフォルダードラッグでも接続できます。
4. ゲームのカードを押して遊びます。

| 環境 | プレイ用 | クリエイター用 |
| --- | --- | --- |
| Windows 10 / 11（64bit） | `GAME-PORTAL-PLAY.exe` | `GAME-PORTAL.exe` |
| Mac（Intel：10.14.6以降／Appleシリコン：11以降） | `GAME-PORTAL-PLAY-MAC.app` | `GAME-PORTAL-MAC.app` |
| HTML（Windows・MacのGoogle Chrome） | `GAME-PORTAL-PLAY.html` | `GAME-PORTAL.html` |

Windows・Macアプリはベータ版です。Mac版はエンジンを同梱し、Chromeの別インストールは不要です。初回の起動準備には時間がかかります。Intel向け互換版の `*-MOJAVE.app` については[Macの案内](docs/MAC.md)を確認してください。HTML版はGoogle Chromeで開き、保存先へのアクセスを許可します。

## プレイ用とクリエイター用の違い

**遊ぶ人はプレイ用、ゲームを登録・管理する人はクリエイター用**を選びます。両方で同じゲームの保存先を使えます。

| 機能 | プレイ用 | クリエイター用 |
| --- | --- | --- |
| ゲーム検索・タグ絞り込み・プレイ | ○ | ○ |
| 対応セーブの保存・書き出し・読み込み | ○ | ○ |
| ゲームの追加・削除・本体更新 | ― | ○ |
| 名前・サムネイル・タグ・開発環境などの編集 | ― | ○ |
| 作品情報の書き出し・読み込み | ― | ○ |
| ほかのPCへの保存先設定の共有（EXE・APP） | ― | ○ |

追加・編集するときは、クリエイター用の **設定 → 編集モード** をオンにします。ゲームごとに名前・画像・タグ・概要・操作方法を設定でき、独自タグは1作品につき32個まで使えます。

HTML・WebゲームのZIP・展開済みフォルダー・Pyxelに対応しています。GodotはWeb書き出し一式、Scratch（sb3）はHTMLへ変換して追加します。WindowsのEXEゲーム対応はベータ版で、MacではEXEゲームを実行できません。詳しい準備・操作はアプリ内の **ヘルプ** にあります。

## ゲームを探しやすくする

カードの「☆ お気に入り」で登録・解除できます。一覧上部で「すべて」「お気に入り」「最近遊んだゲーム」を切り替えられ、履歴は最近30件を表示します。表示サイズは「小さく」「標準」「大きく」から選べます。検索条件は一覧上部に表示され、×ボタンで個別に解除できます。

お気に入り・履歴は利用中のアプリ／ブラウザーのPC内保存領域に記憶します。表示サイズも同じ環境で記憶します。NAS上のゲーム情報には書き込まず、ほかのPCや別のアプリ／ブラウザーへは自動で移りません。

プレイ中の「このPCに保存済み」はPC内へのセーブ完了を示します。NASへの共有状況は「設定」で確認してください。保存に失敗した場合は画面を閉じず、空き容量などを確認して「保存を再試行」を押します。「結果未確認」の作品情報は再保存せず「保存結果を確認」を使います。

## NASで共有する

EXE・APP版では、次の手順でほかのPCの初回フォルダー選択を省けます。

1. 展開した**ランチャー一式**とゲーム保管フォルダーを、同じNAS共有内に置きます。配布フォルダーの配置は保ちます。
2. 最初のPCでNAS上の**クリエイター用EXE／APP**を開き、ゲームの保存先を選びます。
3. **設定 → この保存先を共有**を押して確認します。ランチャーの場所への書き込み権限が必要です。
4. ほかの未設定PCで、同じNAS上のプレイ用またはクリエイター用EXE／APPを開くと、自動で接続します。

NASへのログイン・OSのアクセス許可は各PCで必要です。パスワードは共有設定へ保存しません。個別に保存先を設定済みのPCは、自動では切り替わりません。別々にコピーしたランチャーやゲームフォルダーの間では同期しません。

同じ保存先を使うと、ゲームと作品情報を共有できます。すぐ反映するには **一覧を更新**を押します。通常はホームで3分間操作しないと変更を確認します。対応するセーブも、保存を許可すると共有できます。EXE・Pyxel独自のセーブなどは対象外です。

HTML版では初回のフォルダー選択・アクセス許可がPC・ブラウザーごとに必要です。[HTMLの起動補助](docs/AUTO_CONNECT.md)も利用できます。PC内のゲームはネット接続なしで遊べますが、NAS利用時にはNASへ接続できるネットワークが必要です。

## 保存・バックアップ・更新

| データ | 保存場所 |
| --- | --- |
| ゲーム本体 | 設定で選んだ保存先フォルダー |
| 名前・画像・タグなど | ゲームごとの `.gameportal.json` |
| 対応セーブ | このPCのアプリ／ブラウザー内。共有を許可すると保存先にも同期 |
| お気に入り・最近遊んだ履歴 | 利用中のアプリ／ブラウザー内。ほかのPCとは共有しません |
| 前回の保存先・表示設定 | このPCのアプリ／ブラウザー内 |

バックアップや別PCへの移行では、設定・履歴を含めて**ゲーム保管フォルダー全体**をコピーしてください。アプリ版とHTML版ではPC内のセーブ領域が異なるため、続きを移すときは対応セーブの共有か書き出し・読み込みを使います。[受け渡し手順](docs/TRANSFER_GUIDE.md)にまとめています。

ランチャーを更新するときはアプリを閉じ、最新版ZIPを別の場所へ展開してから入れ替えてください。ゲーム保管フォルダーや、運用中の `GAME-PORTAL-CONNECTION.json`・`GAME-PORTAL-FOLDER.txt` は残します。`_内部ファイル`・`_runtime`・`.app` の中身は削除・変更しないでください。

## 困ったとき

- 接続が止まったら **接続待ちを中止 → 設定** から保存先を選び直します。NASは先にエクスプローラーやFinderで開けるか確認してください。
- 保存先の記憶を削除すると、そのPCでは選び直すまで自動接続しません。ほかのPCの設定やセーブは保持します。
