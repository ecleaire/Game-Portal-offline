# GAME PORTAL

バージョン：**0.23.0**

フォルダーに保存したゲームを、オフラインで探して遊べるアプリです。
**遊ぶときはプレイ専用版、ゲームを追加・管理するときはクリエイター版**を選んでください。

## ダウンロードして使う

**[ZIPをダウンロード](https://github.com/ecleaire/Game-Portal-offline-html/archive/refs/heads/main.zip)**

GitHubの **Code → Download ZIP** からもダウンロードできます。ZIPを展開し、**Windows／Mac／HTML → プレイ用／クリエイター用** の順にフォルダーを開いてください。

開くのは、下の表にある **EXE・APP・HTML** です。詳しい説明は `docs` にまとめています。`_内部ファイル`・`_runtime` はアプリが使うファイルなので、変更・削除せずフォルダーごと保管してください。開発コード・テスト用ファイルは配布ZIPに含まれません。

| 使う環境 | プレイ専用版 | クリエイター版 |
| --- | --- | --- |
| Windows 10 / 11（64bit） | **`GAME-PORTAL-PLAY.exe`** | **`GAME-PORTAL.exe`** |
| Google Chrome（Windows・Mac） | **`GAME-PORTAL-PLAY.html`** | **`GAME-PORTAL.html`** |
| Mac（macOS 12以降） | `GAME-PORTAL-PLAY-MAC.app` | `GAME-PORTAL-MAC.app` |
| Intel Mac（macOS 10.14.6以降） | `GAME-PORTAL-PLAY-MOJAVE.app` | `GAME-PORTAL-MOJAVE.app` |

EXE・Macアプリはベータ版です。MacアプリはGoogle Chromeでゲーム画面を開きます。アプリを終了するときは、画面上部の「GAME PORTAL」メニューを使ってください。[Macでの使い方](docs/MAC.md)

1. 使う環境のフォルダーで「プレイ用」か「クリエイター用」を選び、上の表のファイルを開きます。
2. **ゲームの保存先フォルダーを選びます。** 設定画面の枠へのドラッグでも接続できます。
3. ゲームのカードを押して遊びます。検索やタグで絞り込めます。

ゲームは配布ZIPに含まれていません。共有して遊ぶ場合は、ゲームを管理する人に保存先を確認してください。
**HTMLはブックマークしておくと、次回も開きやすくなります。** ファイルを移動したときは、登録し直してください。

## 目的に合わせて選ぶ

**プレイ専用版**は、ゲームを探して遊ぶためのアプリです。表示設定の変更や、対応しているゲームのセーブの書き出し・読み込みも使えます。

**クリエイター版**は、プレイに加えてゲームの追加・作品情報の編集・ゲーム本体の更新ができます。ゲームを追加・変更するときは、設定の「編集モード」をオンにします。JPG・PNGのサムネイル、説明、操作方法も登録できます。自分のタグを作って、1作品につき32個まで設定できます。ゲーム情報は個別・選択・一括でファイルに保存し、別の保存先へ読み込めます。

HTML・WebゲームのZIP・展開済みフォルダー・Pyxelに対応しています。GodotはWeb用に書き出したファイル一式、Scratch（sb3）はHTMLに変換したファイルを使います。手順は画面内の **「ヘルプ」** で確認できます。

Macでゲームを追加・編集するときは、クリエイター版のChrome画面で保存先を選ぶかドラッグし、書き込みを許可してください。

## 保存先の記憶と共有

同じPCでアクセス許可が残っていれば、前回の保存先に自動接続します。初回や許可が切れたときは、画面の案内に従って保存先を選び、アクセスを許可してください。

接続を待ち続ける場合は、**「接続待ちを中止」** を押し、設定で保存先を選び直してください。

Windows・Mac・HTMLのどれでも、同じNASなどの共有フォルダーを使うと、ゲーム名・タグ・サムネイル・概要・操作方法を共有できます。別々にコピーした保存先の間では同期されません。ホーム画面で3分間操作しないと変更を確認し、セーブ共有に対応しているゲームでは続きを同期します。EXEゲームやPyxel独自のセーブは同期されません。

配布フォルダーを丸ごと置いておくと、アプリの種類を切り替えても共通の接続設定を使えます。13個以上のタグを保存した場合は、共有するPCも **v0.22.0以降** に更新してください。
