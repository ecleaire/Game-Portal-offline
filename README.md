# GAME PORTAL

バージョン：**0.20.20**

ゲームをフォルダーにまとめて、ブラウザーで遊べるオフラインランチャーです。
Windows・MacのPC版Google Chromeで使えます。

**Windowsデスクトップ試作版を追加しました。** `GAME-PORTAL.exe` を開き、初回に保存先を選びます。次回からはアプリ側で前回の保存先へ接続します。フォルダーのドラッグや、設定のパス入力でも接続できます。[使い方・試作版の範囲](docs/DESKTOP.md)

## はじめる

**[ZIPをダウンロード](https://github.com/ecleaire/Game-Portal-offline-html/archive/refs/heads/main.zip)**

1. GitHubの **Code → Download ZIP** からダウンロードし、ZIPを展開します。
2. 展開した `Game-Portal-offline-html-main` の一番上にある **`GAME-PORTAL.html`** をChromeで開きます。
3. **「保存先フォルダーを選ぶ」** でゲームを保管するフォルダーを選び、表示されたカードを押して遊びます。

ゲームは配布ZIPに含まれていません。保存先には、ゲームを入れたフォルダーか、これから追加するための空のフォルダーを選んでください。

**HTMLをブックマークしておくと、次回からすぐ開けます。** ファイルを移動したら登録し直してください。

## ゲームを追加・編集する

設定の **「編集モード」** をオンにし、ホームの **「＋ ゲームを追加」** から追加します。保存の許可が表示されたら許可してください。

HTML・WebゲームのZIP・展開済みのゲームフォルダー・Pyxel（`.pyxapp`）に対応しています。
GodotはWeb書き出し一式を、Scratch（`.sb3`）はHTMLに変換して追加します。

名前・サムネイル・説明などは、ゲームを開いて **「編集」** から変更できます。
詳しい操作やScratchの変換方法は、HTML内の **「ヘルプ」** で確認できます。

## 保存先と次回の起動

同じPC・同じChromeプロファイルで同じ場所のHTMLを開くと、許可が残っていれば前回の保存先へ自動接続します。
別PCで初めて使うときや許可が切れたときは、アクセス許可やフォルダーの選び直しが必要です。

同じNASなどの共有フォルダーを選ぶと、ゲームと作品情報を共有できます。ほかのPCの変更は、ホームで3分ほど操作がないときに反映します。

<details>
<summary>フォルダーを選べないとき</summary>

選択画面が中断・拒否されたら、設定の **「保存先を選ぶ」** をもう一度押して選び直してください。
フォルダーを設定内の **「保存先フォルダーをここへドラッグ」** へドラッグしても接続できます。
「この画面ではアクセス許可を確認できません」と表示されたら、HTMLをアプリ内ではなくPC版Google Chromeで直接開いてください。

</details>

<details>
<summary>起動補助を使う（ベータ版）</summary>

フォルダー選択を省略して遊びたい場合は、起動補助を使えます。

1. 通常のHTMLで保存先を選び、編集モードで初回設定を済ませます。
2. 設定の **「共有・バージョン」** で保存先のパスを入力し、**「起動補助の設定ファイルを保存」** を押します。
3. 保存した `GAME-PORTAL-FOLDER.txt` をHTML・起動補助と同じ場所に置き、次のファイルを開きます。

| PC | 開くファイル |
| --- | --- |
| Windows 10 / 11 | `GAME-PORTAL-WINDOWS.exe` |
| Mac（macOS 12以降） | `GAME-PORTAL-MAC.command`（同じ場所の `GAME-PORTAL-MAC` も必要） |

同じ場所の「ゲーム」フォルダーなら、パスは `./ゲーム` と指定します。NASへの接続・認証はPC側で済ませてください。
接続に失敗したら、保存先や設定を確認して **「自動接続を再試行」** を押します。

自動接続は**プレイ専用**です。セーブは各PCのブラウザー内に保存します。追加・編集・セーブ共有は、HTMLの設定から保存先を選んで行います。

[自動接続の詳しい準備・注意点](docs/AUTO_CONNECT.md) · [WindowsのEXEゲームを使う](docs/WINDOWS_EXE.md)

</details>
