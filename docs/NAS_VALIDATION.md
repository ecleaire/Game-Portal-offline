# NAS共有の検証手順

v0.13.0、2026年10月15日。実NASと2台目PCは未提供のため、本書は実機用手順です。
Windowsローカルでは模擬切断・再接続・競合テストを実施しました。実機の成功記録ではありません。

## ローカルで確認した範囲

- 設定書き込みの失敗：既存の設定を保持し、入力を失わず、保存前履歴を残す。
- close失敗／保存後の確認失敗：「保存結果未確認」とし、このPCに記録。再起動後もフォルダーを指定して照合できる。
- 照合：保存済み・未反映・別の変更を区別。未反映だけ明示再試行し、別の変更を上書きしない。
- 初回投稿の未確認：コピーと投稿途中マーカーを保持し、保存済みの確認後に一覧へ反映する。
- 保存直後の走査失敗：「保存済み／一覧更新だけ失敗」を区別し、再保存しないよう案内。
- 再接続：同じ保管フォルダーの作品IDを維持して最新の設定を読み直す。
- 模擬排他書き込みと古い設定：2操作のうち1件だけ保存し、競合した側を拒否。
- 投稿途中の失敗：今回の投稿フォルダーを片付け、既存作品を保持する。

`npm test` と `npm run test:browser` で確認できます。追加UIの検証は
`tests/offline-html/improvements-browser.mjs`、`tests/offline-html/recovery-browser.mjs`、`tests/offline-html/sync-browser.mjs`、競合・履歴は単体テストにもあります。
ブラウザーとメモリーの模擬排他は、SMBや別PC間のロックを保証しません。

## 実機が用意できたら

実作品から分けた専用の空のテストフォルダーと、2台のPCを使用してください。
各PCで配布HTMLを開き、同じテストフォルダーを指定します。

1. PC Aで初期設定し、小さなHTMLゲームを投稿。PC Bは閲覧モードで自動確認をオンにし、PC Bのホームで3分～3分5秒操作せず、同じ名前・タグ・画像が反映することを確認。再起動後は記憶した投稿先へ戻り、権限失効時は再接続できることを確認。
2. PC Aで設定を開き、接続を切断して保存。成功表示が出ず、入力が残り、既存JSONの内容と作品IDが変わっていないことを確認。
3. 保存後の確認時やclose時の切断も試し、保存済み／未反映を断定せず「保存結果未確認」と表示することを確認。HTMLを開き直しても確認記録が残り、同じフォルダー指定後に照合できることを確認。照合後の未反映だけ明示再試行し、別の変更は上書きしない。
4. 接続を復旧し、「設定」の再接続、またはフォルダー指定で戻す。作品ID・ライブラリIDを再生成せず、履歴と最新の設定を確認。
5. PC AとBで同じ設定を開く。Aが保存完了してからBが保存し、Bが更新済みの案内で止まることを確認。
6. 同時保存はテストフォルダーだけで試す。両方が成功する場合はNASの排他に依存できないため、同時編集禁止の運用とNAS側バックアップを維持する。
7. 投稿のコピー途中に切断し、既存作品が変わらず、不完全な新作品が通常一覧に出ないことを確認。復旧後は点検で投稿途中のマーカーを確認。
8. Bの編集中はAの変更で入力が上書きされず、編集を閉じた後に反映されることを確認。
9. 自動確認中に切断し、一覧が保持され自動確認が停止することを確認。再読み込みまたは再接続で再開する。ライブラリID変更時は操作が止まることを確認。
10. Aで遊んで終了し、ホームで3分待つか「今すぐセーブを同期」。Bで同じ作品を開くと続きが入ることを確認。A/Bで別々に進めてから同期し、競合時は自動上書きせず選択できること、切替前のセーブ履歴が残ることを確認。共有への書込中・読み戻し中の切断と再起動後の再試行で二重保存・進行消失がないことも確認。

記録には日時、アプリ版、OS／Chrome版、NAS／SMB設定、切断の方法、確認したID、
期待結果と実結果を残します。接続情報・パスワード・私物ゲーム・セーブはソースZIPへ入れません。

## 本体更新の実機確認

PC Aの編集モードで投稿済み作品を開き「本体を更新」を実行し、Bの一覧更新後に開き直すと新版が起動することを確認してください。Bでプレイ中なら自動終了しないこと、名前・タグ・画像・概要・操作方法・IDが変わらないことを確認します。準備中・選択JSONのclose中・読み戻し中に切断し、旧版の保持と更新結果未確認を区別してください。前者は元の本体を起動できること、後者は再起動／別PCでも「更新状態を確認」で照合できることを確認します。旧版への復元、更新済み作品フォルダー全体の別保存先へのコピー、各PCのローカル保存・退避履歴の保持も確認してください。同時更新は専用テストフォルダーだけで試し、厳密なPC間排他の実機成功記録として残してください。
