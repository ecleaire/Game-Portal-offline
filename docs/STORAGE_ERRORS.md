# このPCの保存記録にエラーが出たとき

保存結果の確認記録やセーブの退避履歴が壊れている場合、ランチャーは正常な空データとして作り直さず、読み取り・更新を停止します。まだ記録を作っていない状態とは区別します。

- 同じ操作を繰り返して上書きしようとせず、表示されたエラーを控えてください。
- このPCのゲーム画面、アプリ、ブラウザーの保存データを削除しないでください。PC内のセーブや復旧に必要な記録も消える可能性があります。
- ゲーム保管フォルダー全体を、設定・履歴を含めてバックアップしてください。このバックアップだけでは、PC内にしかないセーブは保全できません。
- セーブの書き出しが使える場合は、必要なセーブをJSONへ書き出してください。書き出しは元データの修復ではありません。
- 記録の修復・削除を行う前に、保管フォルダー側の保存結果と、このPC側に残るセーブ・記録を照合する必要があります。共有先や別PCに最新のセーブがあるとは限りません。

予防検証では、空でないはずの記録がnull・数値・真偽値になった場合、配列の要素が欠けた場合、複数画面からの同時更新、古い記録を使った置き換え要求を確認します。不正な記録は自動削除せず、元の状態を保持します。
