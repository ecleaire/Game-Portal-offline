# 保存先に自動接続する（ベータ版）

起動補助からHTMLを開くと、設定済みの保存先に接続してゲーム一覧を表示します。ほかのPCでも、同じ設定から接続できます。
**ゲームを追加・編集するときは、クリエイター版のChrome画面で保存先を選び、書き込みを許可してください。** セーブ共有も、Chromeで保存先への書き込みを許可すると使えます。
プレイ中のセーブは、そのPCのブラウザー内に保存されます。

## 自動接続を設定する

1. `GAME-PORTAL.html`（クリエイター版）をChromeで開き、保存先を選んで「編集モード」をオンにします。書き込みを許可すると初回設定が完了します。既存のゲームやIDはそのまま使えます。
2. HTMLの「設定」→「共有・バージョン」で保存先のパスを入力し、「起動補助の設定ファイルを保存」を押します。保存した `GAME-PORTAL-FOLDER.txt` を **配布フォルダーのREADMEと同じ場所** に置きます。UTF-8のテキストで、パスだけを1行で書いて作ることもできます。引用符は不要です。
3. READMEと同じ場所の「ゲーム」フォルダーなら `./ゲーム` と書きます。フォルダー名は自由です。配布一式を使う場合、相対パスはREADMEのある場所が基準です。HTMLの用途別フォルダーだけをコピーした場合は、HTMLのある場所に設定ファイルを置きます。

```text
共有フォルダー/
├ README.md
├ Windows/
├ Mac/
├ HTML/プレイ用/GAME-PORTAL-PLAY.html
│             └ 起動補助/
├ _内部ファイル/          ← 変更しません
├ GAME-PORTAL-FOLDER.txt  ← 内容は ./ゲーム
└ ゲーム/
```

同じ配置なら、Windowsのドライブ文字やMacのNASマウント名が違っても使えます。
Windowsだけで使う場合は `\\NAS名\共有名\ゲーム`、Macだけなら `/Volumes/共有名/ゲーム` のような絶対パスも指定できます。
両方で使う場合は相対パスにしてください。NASへの接続・認証とOS側の読み取り権限は必要です。

## 設定した保存先を開く

- **Windows 10 / 11**：HTMLの横にある「起動補助」→ `Windowsで起動.cmd` を開きます。
- **Mac（Intel：macOS 10.14.6以降／Appleシリコン：macOS 11以降）**：「起動補助」→ `Macで起動.command` を開きます。起動中はTerminalのウィンドウを残します。閉じると接続が終了します。

ブラウザーにゲーム一覧が開きます。カードを押すと遊べます。
設定ファイルがなければフォルダー選択から使えます。後から設定ファイルを置いた場合も「自動接続を再試行」で接続できます。
設定が誤っている・NASが未接続・初回設定が未完了の場合もHTMLは開き、案内を表示します。「設定」から保存先を選び直せます。空の保存先を勝手に作りません。
起動時にNASが未接続だった場合や、設定ファイルを修正した場合は「自動接続を再試行」を押してください。HTMLや起動補助を開き直さずに再確認できます。一度つながった保存先は起動補助を終了するまで固定します。別の保存先へ変えるときは起動補助を開き直すか、HTMLの設定から選んでください。
接続を待ち続ける場合は「接続待ちを中止」で戻り、再試行できます。待機中もヘルプ・設定を開けます。中止するのは起動補助への読み取りだけで、セーブの保存は強制中断しません。
同じタブで再読み込みしても、起動補助が動いていれば自動接続を引き継ぎます。接続情報はそのタブの履歴にだけ保持し、別のHTMLや新しく開くタブへは引き継ぎません。手動で保存先を選び直すと、元の自動接続先へ戻らなくなります。
起動補助を終了した場合や新しいタブで開く場合は、起動補助から開き直してください。
ゲーム素材の合計200MB・500ファイル、ZIP・PYXAPPの50MB上限を確認してから読み込みます。容量超過の場合は一覧へ戻り、ゲームの書き出し内容を確認してください。


保存先との一時的な接続エラーは、ホームで同じ保存先への読み取り接続を自動で再試行します。最初は約15秒後、失敗が続く場合は最大1分間隔です。検索条件はそのまま残し、ゲーム中・編集中・セーブ処理中・保存結果の確認中は待ちます。許可が切れた場合や保存先IDが変わった場合は、設定から接続を確認してください。書き込みや未確認の保存処理は自動で繰り返しません。保存先は選択ボタン・ドラッグのどちらでも読み取りから接続し、書き込み許可は追加・編集の際に確認します。選択画面が中断した場合は、「保存先を選ぶ」で選び直すか、設定内の枠へフォルダーをドラッグしてください。キャンセルとアクセス制限はエラー名だけでは区別できません。許可を要求できない表示環境では、HTMLをPC版Google Chromeで直接開いてください。

## Macで使う

Macアプリで起動する場合は、[Macでの使い方](MAC.md)を参照してください。アプリに画面用HTMLを内蔵しています。

`Macで起動.command` はIntel MacではmacOS 10.14.6以降、AppleシリコンではmacOS 11以降に対応します。ゲームごとの動作条件も確認してください。

配布ZIPは `Windows`・`Mac`・`HTML` の下に `プレイ用`・`クリエイター用` を分けています。配布フォルダーを丸ごと使う場合、`GAME-PORTAL-CONNECTION.json` と `GAME-PORTAL-FOLDER.txt` はREADMEと同じ場所が共通の設定先です。版のフォルダーだけを別の場所へコピーした場合は、その場所で保存先を指定してください。
