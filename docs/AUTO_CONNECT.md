# 保存先へ自動接続（ベータ版）

起動補助からHTMLを開くと、別PCでもフォルダー選択なしでゲーム一覧を開けます。
**試用版はプレイ専用です。追加・編集・セーブ共有は通常のHTMLからフォルダーを選んで行います。**
プレイ中の対応セーブは、そのPC・ブラウザー内に保存します。

## 準備する人

1. 通常の `GAME-PORTAL.html` で保存先を選び、編集モードで初回設定を済ませます。既存のゲームやIDはそのまま使います。
2. HTMLの「設定」→「共有・バージョン」で保存先のパスを入力し、「起動補助の設定ファイルを保存」を押します。保存した `GAME-PORTAL-FOLDER.txt` をHTML・起動補助と同じ場所に置きます。UTF-8のテキストで、パスだけを1行で書いて作ることもできます。引用符は不要です。
3. 保存先が同じ場所の「ゲーム」フォルダーなら `./ゲーム` と書きます。フォルダー名は自由です。相対パスはHTMLのある場所を基準にします。

```text
共有フォルダー/
├ GAME-PORTAL.html
├ GAME-PORTAL-WINDOWS.exe
├ GAME-PORTAL-MAC
├ GAME-PORTAL-MAC.command
├ GAME-PORTAL-FOLDER.txt  ← 内容は ./ゲーム
└ ゲーム/
```

同じ配置なら、Windowsのドライブ文字やMacのNASマウント名が違っても使えます。
Windowsだけで使う場合は `\\NAS名\共有名\ゲーム`、Macだけなら `/Volumes/共有名/ゲーム` のような絶対パスも指定できます。
両方で使う場合は相対パスにしてください。NASへの接続・認証とOS側の読み取り権限は必要です。

## 遊ぶ人

- **Windows 10 / 11**：`GAME-PORTAL-WINDOWS.exe` を開きます。
- **Mac（macOS 12以降、Intel・Appleシリコン）**：`GAME-PORTAL-MAC.command` を開きます。起動中はTerminalのウィンドウを残します。閉じると接続が終了します。

画面は共通のHTMLです。通常のブラウザーが開き、ゲームカードから遊べます。
設定ファイルがなければフォルダー選択から使えます。後から設定ファイルを置いた場合も「自動接続を再試行」で接続できます。
設定が誤っている・NASが未接続・初回設定が未完了の場合もHTMLは開き、案内を表示します。「設定」から保存先を選び直せます。空の保存先を勝手に作りません。
起動時にNASが未接続だった場合や、設定ファイルを修正した場合は「自動接続を再試行」を押してください。HTMLや起動補助を開き直さずに再確認できます。一度つながった保存先は起動補助を終了するまで固定します。別の保存先へ変えるときは起動補助を開き直すか、HTMLの設定から選んでください。
接続を待ち続ける場合は「接続待ちを中止」で戻り、再試行できます。待機中もヘルプ・設定を開けます。中止するのは起動補助への読み取りだけで、セーブの保存は強制中断しません。
同じタブで再読み込みしても、起動補助が動いていれば自動接続を引き継ぎます。接続情報はそのタブの履歴にだけ保持し、別のHTMLや新しく開くタブへは引き継ぎません。手動で保存先を選び直すと、元の自動接続先へ戻らなくなります。
起動補助を終了した場合や新しいタブで開く場合は、起動補助から開き直してください。
ゲーム素材の合計200MB・500ファイル、ZIP・PYXAPPの50MB上限を確認してから読み込みます。容量超過の場合は一覧へ戻り、ゲームの書き出し内容を確認してください。


保存先との一時的な接続エラーは、ホームで同じ保存先への読み取り接続を自動で再試行します。最初は約15秒後、失敗が続く場合は最大1分間隔です。検索条件はそのまま残し、ゲーム中・編集中・セーブ処理中・保存結果の確認中は待ちます。許可が切れた場合や保存先IDが変わった場合は、設定から接続を確認してください。書き込みや未確認の保存処理は自動で繰り返しません。保存先は選択ボタン・ドラッグのどちらでも読み取りから接続し、書き込み許可は追加・編集の際に確認します。選択画面が中断した場合は、「保存先を選ぶ」で選び直すか、設定内の枠へフォルダーをドラッグしてください。キャンセルとアクセス制限はエラー名だけでは区別できません。許可を要求できない表示環境では、HTMLをPC版Google Chromeで直接開いてください。

## Macの対応範囲

起動補助は **macOS 12以降のIntel / Appleシリコン** 向けです。2015年以降のMacでもOSとゲームの動作条件を確認してください。
2015年のMacBook Airなど、公式に更新できるOSがMontereyまでの機種があります。
最新ChromeはmacOS 13以降が必要で、Monterey向けChromeは150が最終です。古いChromeの導入を推奨するものではありません。
起動補助のOS条件を満たしても、すべてのゲーム・ブラウザーの動作を保証しません。Windows用EXEゲームはMacでは実行できません。

起動補助にはAppleの公証はありません。macOSが開く操作を制限した場合は、入手元を確認したうえでmacOSの通常の「開く」許可操作を行ってください。セキュリティ機能全体を無効にする必要はありません。
Mac実機・実NASでの手動確認は未実施です。

参考：[Chromeの動作条件](https://support.google.com/chrome/a/answer/7100626?hl=ja) · [MacBook Airの対応OS](https://support.apple.com/102869)
