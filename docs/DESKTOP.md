# Windowsアプリ（ベータ版）

デスクトップ版：**0.3.0-beta.16** ／ 内蔵ランチャー：**0.24.21**

ゲームを探して遊ぶときは `GAME-PORTAL-PLAY.exe`、ゲームを追加・管理するときは `GAME-PORTAL.exe` を開きます。クリエイター版でもゲームを探して遊べます。保存先の選択・記憶・読み書きはアプリが行うため、Chromeでフォルダーへのアクセスを許可する操作は不要です。

## はじめる

1. [バージョン付きZIP](../README.md#ダウンロードして使う)をダウンロードし、展開します。
2. **Windows → プレイ用／クリエイター用** を開き、プレイ専用版の **`GAME-PORTAL-PLAY.exe`**、またはクリエイター版の **`GAME-PORTAL.exe`** を起動します。
3. 初回は **「保存先フォルダーを選ぶ」** でゲームの保管場所を選びます。

同じWindowsユーザーでアプリを開くと、次回からは前回の保存先に接続します。クリエイター版でゲームを追加・変更するときは、設定の「編集モード」をオンにしてください。保存先は設定の「保存先を選ぶ」で変更できます。接続前のホーム画面や、設定画面の枠へフォルダーをドラッグする方法も使えます。

`GAME-PORTAL-WINDOWS.exe` は、HTMLをChromeで開いて使う人向けの起動補助です。[使い方はこちら](WINDOWS_EXE.md)。

## 保存先のパスを入力する

保存先は、フォルダーの選択・ドラッグ・パス入力のいずれでも指定できます。セーブ共有に対応しているゲームでは、プレイ専用版でもセーブを保存・同期できます。

設定の **「保存先のパス」** に、エクスプローラーのアドレス欄からコピーしたパスを貼り付け、**「このパスに接続」** を押します。Enterキーでも接続できます。NASは `\\NAS名\共有名\ゲーム` のような共有フォルダーのパスを指定します。ネットワークドライブのパスも使用できます。

フォルダー選択画面のアドレス欄へパスを貼り付ける方法や、設定内の枠へフォルダーをドラッグする方法も使えます。NAS名だけでなく共有名まで指定し、先にエクスプローラーで開けることを確認してください。接続できないパスを指定した場合は、現在の保存先を保持します。

## 保存先とセーブ

ほかのPCの初回設定を省くには、ランチャー一式とゲームの保管フォルダーを同じNASの共有フォルダー内に置きます。最初のPCでクリエイター用を開いて保存先を選び、**設定 → この保存先を共有**を押してください。未設定のPCは、同じNAS上のプレイ用・クリエイター用EXE／APPを起動すると、共有された保存先へ自動で接続します。

共有先の変更も同じボタンから行います。プレイ専用版からは変更できません。確認中に別PCが共有設定を変更した場合は上書きを止めます。個別に保存先を記憶済みのPCは、自動では切り替えません。

旧版の保存ロックが残っている場合は、**すべてのPCで旧版のランチャーを閉じてから**、クリエイター用の **この保存先を共有** を押し、確認画面で解除してください。中身のない旧版のロックフォルダーだけが対象です。更新後のロックファイルは通常の動作で残りますが、手動で削除しないでください。

アプリとゲームの保存先が同じNAS共有内にある場合、一度保存先を選ぶと、配布フォルダーの一番上（READMEと同じ場所）に `GAME-PORTAL-CONNECTION.json` を作成します。ほかのPCで同じ場所のアプリを開くと、この設定から保存先に接続します。アプリとゲームの保存先を1つのフォルダー内にまとめておくと、フォルダー全体を別の場所に移しても使えます。NASに書き込めない場合は、選んだ保存先をそのPCにだけ記憶します。

この接続設定には、保存先の相対パスとIDを記録します。パスワードやセーブは含まれません。NASへのサインインは各PCで行ってください。そのPCで選んだ保存先があれば、そちらを優先します。保存先を選び直しても、共有の接続設定は自動で上書きしません。

WindowsとMacで同じNASを使う場合は、[Macでの使い方](MAC.md)も参照してください。

- これまで使っていたゲームの保存先も開けます。ゲームID・作品情報・更新履歴の形式はHTML版と共通です。初めて使うときは、コピーした保存先で動作を確認してください。
- 保存先のパスと、このアプリ内のセーブはWindowsユーザーごとの `%LOCALAPPDATA%\GamePortalDesktop` に記憶します。EXEだけを別PCへ渡しても、このPCの設定・個人セーブは含まれません。
- Chrome内のセーブは自動移行しません。必要なセーブはHTML版から書き出し、このアプリで読み込んでください。セーブ共有に対応しているゲームでは、同期済みのセーブを同じ保存先から読み込めます。
- NASへの接続・認証、Windows側の読み取り・保存権限は必要です。保存先が見つからないときは接続を戻すか、設定から選び直します。

## 動作環境と注意点

Windows 11 x64・Microsoft Edge WebView2 Runtimeがある環境で検証しています。WebView2 RuntimeがないPCでは、[Microsoftの配布案内](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution)を確認してください。アプリにHTML・ゲーム実行用ランタイム・WebView2の接続部品を内蔵していますが、WebView2 Runtime本体は内蔵していません。

アプリでの再起動・追加・編集・プレイ・セーブを検証しています。実NAS・物理的な別PC・HTML版との同時編集は未検証です。大切なゲームを保存したフォルダーを使う前にバックアップを取り、HTML版との同時編集は避けてください。ベータ版のEXEにコード署名はありません。

MacではHTML版、または[Macアプリ](MAC.md)を使ってください。プレイ専用版とクリエイター版があります。

## 開発する人へ

Windowsと.NET FrameworkのC#コンパイラーを使用します。

```sh
node scripts/build-desktop.mjs --prepare
node scripts/verify-desktop.mjs
node tests/desktop-files.mjs
node tests/desktop-browser.mjs
```

初回のビルドだけMicrosoft公式NuGetから固定版SDKを取得し、`desktop/desktop.json` のSHA-256と照合します。生成したEXEはSDK DLLや隣のHTMLがなくても起動できます。ライセンスはアプリ内ヘルプと `DESKTOP-LICENSES.txt` に含みます。

[READMEへ戻る](../README.md)

配布ZIPは `Windows`・`Mac`・`HTML` の下に `プレイ用`・`クリエイター用` を分けています。配布フォルダーを丸ごと使う場合、`GAME-PORTAL-CONNECTION.json` と `GAME-PORTAL-FOLDER.txt` はREADMEと同じ場所が共通の設定先です。版のフォルダーだけを別の場所へコピーした場合は、その場所で保存先を指定してください。
