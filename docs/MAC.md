# Macで使う

同じ配布フォルダーのクリエイターで保存先を選ぶと、同じPCのプレイ用へ反映します。起動済みのプレイ用はホームで確認し、ゲーム中や保存中は切り替えを待ちます。HTML版は同じChromeプロファイルで開いてください。Chromeの許可が必要な場合は「アクセスを許可して開く」を押します。別PCや別のブラウザープロファイルへ権限を渡す機能ではありません。セーブ・お気に入りの保存場所も変更しません。

Mac版は表示エンジンを同梱したアプリです。Google Chromeの別インストールや、ブラウザーのフォルダーアクセス許可は不要です。

## はじめる

1. [バージョン付きZIP](../README.md#ダウンロードして使う)をダウンロードし、ZIPを展開します。
2. **Mac → プレイ用／クリエイター用** を開きます。
3. 遊ぶときは `GAME-PORTAL-PLAY-MAC.app`、追加・編集も行うときは `GAME-PORTAL-MAC.app` を開きます。
4. 初回の起動準備が終わったら、ゲームの保存先を選びます。設定画面へのフォルダードラッグや、パスの貼り付けでも接続できます。
5. ゲームのカードを押して遊びます。

対応OSは **Intel：macOS 10.14以降／Appleシリコン：macOS 11以降** です。10.14.4を含むMojaveに対応する起動条件へ変更しました。必要な実行ファイルを一式で同梱するため、アプリや起動補助の内部ファイルを取り出さず使用してください。Intel向けの互換版も、アプリ内で画面を表示します。

表示エンジンも `.app` の中に入っています。**アプリ全体をコピーして使えます。** 初回だけ、このMac内にエンジンを準備します。起動時のダウンロードはありません。共有の接続設定も一緒に使う場合は、配布フォルダー全体をまとめて保管してください。

## 次回の起動と保存先

前回選んだ保存先を、このMacに記憶します。次回はアプリを開くと再接続します。NASを使う場合は、先にFinderで共有フォルダーを開けることを確認してください。NASへの接続・認証やmacOSのアクセス確認が出たときは、画面の案内に従います。

接続が進まない場合も、ホームや設定を操作できます。**接続待ちを中止 → 設定** から選び直すか、保存先を枠へドラッグしてください。

## 追加・編集とセーブ

クリエイター版で **設定 → 編集モード** をオンにすると、ゲームの追加・作品情報の編集・本体の更新ができます。読み書きはアプリが行います。プレイ専用版では作品を変更できません。

セーブはこのアプリ内に保存します。Chromeとは保存場所が異なります。続きを移す場合は、対応セーブの共有か、書き出し・読み込みを使ってください。

アプリを閉じるときはセーブの保存を確認します。保存中や未保存の編集がある場合は、画面に戻って完了してから閉じてください。

## Windows・HTMLと共有する

同じゲーム保存先を使えば、ゲーム名・タグ・サムネイル・概要・操作方法などを共有できます。ホームで3分間操作しないと変更を確認します。すぐ反映するには **一覧を更新** を押します。

同じNASの共有フォルダー内にランチャー一式とゲーム保存先を置き、クリエイター用の **設定 → この保存先を共有** で登録します。共通の `GAME-PORTAL-CONNECTION.json` に相対パスと保存先IDを保存します。未設定のMac・Windows PCは同じNAS上のアプリを開くだけで接続し、アプリ内でのフォルダー選択は不要です。

保存先を選び直すだけでは、共有先を勝手に置き換えません。共有先も変更するときは、もう一度 **この保存先を共有** を押します。個別に保存先を記憶済みのPCは変更しません。確認中に別PCが共有先を変更していた場合は、上書きを止めて再確認を求めます。

旧版の保存ロックが残っている場合は、**すべてのPCで旧版のランチャーを閉じてから**、クリエイター用の **この保存先を共有** を押し、確認画面で解除してください。中身のない旧版のロックフォルダーだけが対象です。更新後のロックファイルは通常の動作で残りますが、手動で削除しないでください。

接続設定にパスワードやアクセス権は含まれません。NASへの接続は各PCで行ってください。別々にコピーしたゲームフォルダー間では、自動同期しません。

## 開けないとき

Mojave 10.14では、ZIPを展開した中の **Mac → プレイ用／クリエイター用** からアプリを直接開いてください。更新直後はDockや「最近使った項目」に古いアプリが残ることがあります。Finderでアプリを選び **情報を見る** からバージョンを確認できます。

同じ用途のアプリは1つだけ開きます。プレイ用とクリエイター用は同時に使用できますが、同じ作品を編集している間は、その作品のプレイや別PCでの編集を終えてから更新すると確認しやすくなります。

起動用接続はMac内の127.0.0.1だけを使い、インターネット接続は不要です。「bind / POSIX 48」は保存済みポートが使用中の状態です。同じ用途のアプリを終了し、少し待って開き直してください。解消しない場合はMacを再起動します。ポート設定・ゲーム保管フォルダー・セーブを削除する必要はありません。

起動できない場合は、ダイアログのバージョンとエラー全文、macOSのバージョンを確認してください。アプリの接続エラーと、FinderでNASを開けない問題は別です。NAS接続はFinderで先に確認してください。

macOSがアプリの起動を止めた場合は、配布元を確認したうえでFinderから右クリックして **開く** を選びます。管理されたPCでは管理者に確認してください。

「内蔵エンジンが見つかりません」と表示されたら、ZIPを展開し直し、アプリ全体をコピーしてください。アプリ内のファイルを取り出したり、変更したりする必要はありません。

Windows用のEXEゲームはMacでは動きません。HTMLなどのWeb版を使ってください。

HTML版やHTML用の起動補助を使う場合は、対応するGoogle Chromeが必要です。
