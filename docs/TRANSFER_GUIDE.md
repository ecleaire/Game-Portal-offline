# 別のPC・他の人へ渡す

## ランチャーを渡す

[最新版ZIP](https://github.com/ecleaire/Game-Portal-offline/archive/refs/tags/v0.24.17.zip)を展開し、フォルダー一式を渡します。相手は **Windows／Mac／HTML → プレイ用／クリエイター用** から選んで起動します。[起動ファイルの一覧](../README.md#ダウンロードして使う)を確認してください。

インストール・ビルド・アカウント登録は不要です。Macアプリはエンジン同梱、HTML版はGoogle Chromeを使います。`_内部ファイル`・`_runtime`・`.app` 内のファイルはそのまま残します。配布ZIPにはゲーム・個人のセーブ・保存先の接続設定は含みません。

通常は相手のPCで保存先を選びます。同じNAS上のEXE・APPを使う場合は、クリエイター用の **設定 → この保存先を共有** で、未設定PCの初回選択を省けます。[NAS共有の手順](../README.md#nasで共有する)を確認してください。NASへのログイン・OSのアクセス許可は各PCで必要です。HTML版のフォルダー許可も引き継げません。

## ゲームごと移す・バックアップする

1. 投稿・編集・本体更新・セーブを完了し、ゲームを閉じます。保存結果が未確認の場合は、先に画面の案内から確認します。
2. **ゲーム保管フォルダー全体**をUSBや別の保存先へコピーします。ゲーム本体に加え、`.gameportal.json`・`.gameportal`・更新済み作品の `.gameportal-content.json`・`.gameportal-versions` も含めます。
3. 相手のPCでランチャーを開き、受け取った保管フォルダーを選びます。投稿・編集する場合だけ、クリエイター用で編集モードをオンにします。

フォルダー名やドライブは変えられますが、ライブラリID・作品IDは変更しません。Webゲームの素材は元の相対配置を保ちます。コピー後の別々のフォルダーは自動同期しないため、継続して共有する場合は同じNASの保存先を使います。

各PCのランチャーは対応版へそろえてください。最低対応はv0.14.0、拡張タグのある保存先はv0.22.0以降です。必要版の案内が出た場合はランチャーを更新し、互換性情報の削除やIDの作り直しでは回避しません。

## セーブも移す

対応するゲームは、元PCでゲームを終了し **設定 → 今すぐセーブを同期** を実行してから、相手PCで同じ保存先へ接続すると続きを引き継げます。共有先への保存許可が必要です。競合の案内が出た場合は、内容を確認して使うセーブを選んでください。

個別に渡す場合は、ゲーム画面の **セーブ書き出し**で保存し、相手PCで同じゲームを開いて **セーブ読み込み**を使います。PC内のセーブ履歴は、履歴画面の **JSONに書き出す**で退避できます。

アプリとHTMLのセーブ領域は別です。ランチャーやゲームフォルダーをコピーするだけでは、PC内だけにあるセーブ・履歴は移りません。EXE・Pyxel独自のセーブなどは同期対象外で、各ゲームの方法に従って移してください。

## 開かないとき

ZIPを展開済みか、OSに合う起動ファイルを使っているかを確認します。HTML版はプレビュー画面ではなくPC版Google Chromeで開きます。NASには先にエクスプローラーやFinderで接続し、読み取り・保存権限を確認してください。

作品だけ動かない場合は、アプリの **ゲームを点検**で不足ファイルや設定を確認します。操作手順はアプリ内の **ヘルプ**にもあります。
