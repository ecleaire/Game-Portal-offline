# 別のPC・他の人へ渡すとき

## ランチャーだけ渡す

GitHubの「Code → Download ZIP」で取得したZIPを展開し、`Game-Portal-offline-html-main` 内の `GAME-PORTAL.html` をPC版Google Chromeで開いてください。展開済みフォルダーを相手のPCへコピーしても使えます。
HTMLの中に必要な画面・ゲーム実行用ランタイムを同梱しているため、インストール、Node.js、開発ソース、アカウント、APIキー、インターネット接続は不要です。
この配布ZIPにはゲーム・個人のセーブ・元PCの投稿先設定を含めません。
初回はホームの「保存先フォルダーを選ぶ」、または「設定」→「保存先を選ぶ」で、そのPCから利用できる保管フォルダーを選び、Chromeのアクセスを許可します。
操作に迷った場合は、画面上部またはゲーム画面の「ヘルプ」で基本手順を確認できます。
初期状態は閲覧モードです。投稿・編集する人だけ「編集モード」をオンにしてください。

WindowsのEXEゲーム対応はベータ版です。使う場合は、同じフォルダーの `GAME-PORTAL-WINDOWS.exe` を開きます。「Code → Download ZIP」に起動補助も含まれています。メイン画面は同じHTMLです。[EXEゲームの手順](WINDOWS_EXE.md)を参照してください。EXEのセーブはゲーム自身が管理します。

## 起動から投稿・プレイまで

1. `GAME-PORTAL.html` を開き、ゲーム保存先フォルダーを指定します。記憶済みで許可が残っている場合は自動接続します。
2. 投稿する人は、設定で「編集モード」をオンにします。
3. ランチャーの「ゲームを追加」から、ゲームのHTML・WebゲームZIP・PYXAPP、またはWeb書き出しフォルダーを選びます。
4. 投稿前チェックと保存先を確認し、「追加する」を押します。ここで指定フォルダーへゲームをコピーします。投稿元は変更しません。
5. 投稿後に名前・タグ・画像・概要・操作方法を設定します。「あとで設定」でもゲームは残ります。
6. 一覧のゲームカードをクリックしてプレイします。編集モードでは、開いたゲームの「編集」から情報を変更できます。

この「アップロード」は、選んだゲームを指定フォルダーへコピーして保存する操作です。

## HTMLのバージョンをそろえる

共有前に全PCのHTMLを v0.14.0 以降の対応版へ交換してください。設定にはこのHTMLの版とフォルダーの必要版を表示します。必要版より古いHTML・不明な必須機能・壊れた互換性情報では、新規起動と投稿・編集を停止します。互換性のある異なるパッチ版は利用できます。
編集を有効にした時点で `.gameportal/compatibility.json` を保存します。閲覧だけでは作成しません。フォルダー移行時はこの情報も含めてコピーしてください。
v0.13.1以前には判定処理がないため、後から自動停止できません。更新前の本体を起動する可能性があります。管理する人が各PCの古いHTML・ショートカットを交換してください。互換性情報の削除・必要版の引き下げで回避せず、対応HTMLに交換し再読み込みしてください。壊れている場合は管理者がバックアップと照合します。

## 同じゲームを共有する

各PCでOSからアクセスできる同じNAS共有フォルダーを選びます。
投稿先の記憶とアクセス許可は各PCで設定します。元PCの絶対パスや許可は相手へ引き継ぎません。
ゲームと、ゲームごとの名前・タグ・画像・概要・操作方法は共有フォルダーに保存され、ホームで3分ほど操作がないときに自動で反映されます。
同じ名前の別フォルダーを選んでも共有にはなりません。NASの接続・アクセス権はOS側で設定してください。

## NASを使わずゲームごと移す

編集・投稿を完了し、ゲームを閉じてから、保管フォルダー全体をUSBなどでコピーしてください。
ゲーム本体だけでなく、各ゲームの `.gameportal.json` と管理・履歴用の `.gameportal` フォルダーも含めます。本体更新済みの作品では、作品内の `.gameportal-content.json` と `.gameportal-versions` も必要です。作品フォルダーを丸ごとコピーしてください。
フォルダー名や保存するドライブは相手のPCで変更して構いません。ライブラリID・作品IDは変更しないでください。
相手は受け取った保管フォルダーを選ぶだけで、作品の情報・画像・履歴を読み込めます。
Webゲームの素材・JS・WASM・PCKなども、元の相対配置のままコピーします。
ランチャーHTMLはゲーム保管フォルダーの外へ置いてください。

コピーした別々のフォルダーは、その後は別々に更新されます。継続して共有する場合は同じNASを選んでください。
投稿・保存の結果が未確認のものは、元PCの「保存結果を確認」で照合してから移してください。情報設定の確認待ち記録は相手PCへ引き継ぎません。本体更新の確認記録は作品内に保存しますが、移す前に更新状態を確認しておくことを推奨します。

## セーブも移す場合

v0.20.0以降では、対応セーブを共有フォルダー経由で引き継げます。元PCのゲームを終了し、「設定」→「今すぐセーブを同期」を実行してから、相手PCで同じ保管フォルダーを選びます。共有前に閉じたセーブは元PC内だけに残るため、先に同期してください。各PCのブラウザー内の履歴は自動で移りません。
必要なゲームを元PCで開いて「セーブ書き出し」を使用し、相手PCで同じゲームを開いて「セーブ読み込み」で取り込みます。
自分のセーブを他の人へ渡すかは必要に応じて選んでください。

## 開かない・動かない場合

- ZIPを展開してからHTMLをChromeで開きます。メールやクラウドサービスのプレビュー画面では起動しません。
- フォルダーが未選択なら「設定」から指定します。許可が切れたら「再接続する」で許可してください。
- 投稿・編集できない場合は編集モードとフォルダーの書き込み権限を確認します。
- 作品だけ動かない場合は「ゲームを点検」で不足ファイルや壊れた設定を確認します。
- モバイルChrome・Safari・Firefoxは対象外です。組織の端末でローカルHTMLやフォルダーアクセスが禁止されている場合は管理者の設定確認が必要です。

物理的な別PC・実NAS・2015年Mac実機での動作は未確認です。Windowsの専用Chromeプロファイルで、HTMLの移動・改名、ゲーム情報の移行とオフライン実行を確認しています。macOSのIntel・AppleシリコンのCIでは、起動補助の接続・プレイ・保存・復旧を確認しています。Chromeの実際のフォルダー選択・許可ダイアログと、実NASの切断・同時編集は別途実機確認が必要です。

セーブ履歴（v0.15.0以降）はこのPCのChrome内だけに残ります。別PCへ渡す退避は、ゲーム画面の「セーブ履歴」→「JSONに書き出す」で取り出してください。HTMLや保管フォルダーのコピーだけでは移りません。

## 保存先付きHTML

保存先を選んだ後、「設定」→「共有・バージョン」→「共有用HTMLを保存」でGAME-PORTAL-SHARED.htmlを作れます。NASなどのパスは案内用として入力できます。別PCは初回だけ案内された同じ共有フォルダーを選んで許可します。ゲーム・情報・セーブ・アクセス許可はHTMLに含まれません。接続後は共有フォルダーのゲーム情報を自動確認します。パスを変えたらHTMLを作り直して配ります。
